### Corrected and Summarized Key Information:

#### **Device Name**:
米家扫地机器人 (Model: SDJORO1RR)

#### **Key Features**:
- Laser-based path planning with real-time room mapping  
- Multi-sensor navigation (laser, ultrasonic, cliff, wall sensors)  
- Auto-recharge and resume mid-clean  
- App control (Mi Home app) for remote scheduling/monitoring  
- Three cleaning modes (Quiet/Standard/Max)  
- Virtual wall support (optional accessory)  
- Self-diagnosis and error alerts  

---
### **States & Indicators**:

1.  **Ring Light Colors**:
    - **White**: Battery >50%  
    - **Yellow**: Battery 20%-50%  
    - **Red**: Battery <20%  
    - **Breathing White**: Charging/Starting  
    - **Red Fast Flash**: Error state  

2.  **Wi-Fi LED**:
    - **Off**: Wi-Fi inactive  
    - **Slow Flash**: Waiting for connection  
    - **Fast Flash**: Connecting  
    - **Solid**: Connected  

---
### **Operations & Behaviors**:

#### **Basic Controls**:
- **Power**: Long-press (○) to turn on/off  
- **Start/Pause**: Short-press (○)  
- **Return to Dock**: Short-press (↖)  
- **Spot Clean**: Long-press (↖) (1.5m² area)  

#### **Modes**:
1. **Full Clean**: Maps room → partitions → Z-shaped path  
2. **Spot Clean**: Focused 1.5m² square  
3. **Scheduled Clean**: Via app  
4. **Quiet/Standard/Max**: Adjust suction power  

#### **Auto Behaviors**:
- Auto-dock when battery <20%  
- Resume cleaning after recharge  
- Auto-sleep after 10min inactivity  
- Virtual wall avoidance  

---
### **Maintenance**:
- **Weekly**: Clean main brush, side brush, dustbin, filter  
- **Monthly**: Clean wheels, sensors, charging contacts  
- **3-6 Months**: Replace side brush  
- **6-12 Months**: Replace main brush  
- **3 Months**: Replace filter  

---
### **Troubleshooting**:
| **Error** | **Solution** |  
|-----------|--------------|  
| Laser blocked | Clear obstruction |  
| Wheel stuck | Remove debris |  
| Dustbin missing | Reinstall properly |  
| Low battery | Recharge |  
| Wi-Fi issues | Reset via (○ + ↖) |  
| System freeze | Press reset button |  

---
### **Safety Notes**:
- **Do NOT use** on wet surfaces/non-flat areas  
- Keep away from cliffs (e.g., stairs)  
- Avoid vacuuming liquids/sharp objects  
- Supervise children/pets during operation  
- Use only original charger/battery  

---
### **Specs**:
- **Dimensions**: 345×345×96mm (Robot), 230×109×129mm (Dock)  
- **Battery**: 14.4V/5200mAh (4hr charge)  
- **Weight**: 3.8kg  
- **Noise**: <65dB (Quiet Mode)  
- **Wi-Fi**: 2.4GHz  
- **Sensors**: LDS, cliff ×4, ultrasonic, wall-follow
